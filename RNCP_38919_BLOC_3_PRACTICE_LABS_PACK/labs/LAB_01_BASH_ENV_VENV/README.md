# LAB 01 — Bash, variables d'environnement et venv

## Objectifs

- utiliser `export` ;
- comprendre `.bashrc` ;
- lire une variable avec Python ;
- créer et activer un venv.

## Exercices

1. Exporter `APP_ENV=practice` et `API_PORT=8000`.
2. Vérifier avec `echo` et `env`.
3. Ajouter `APP_ENV=practice` dans `.bashrc`, puis `source ~/.bashrc`.
4. Exécuter le starter Python.
5. Créer `.venv`, l'activer et vérifier `which python`.
