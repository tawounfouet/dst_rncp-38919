# RNCP 38919 — Bloc 2 — Examen blanc 01 + Practice Labs

Ce pack regroupe un **examen blanc complet**, son **corrigé**, un **starter project**
et **7 labs progressifs** pour pratiquer les briques annoncées dans le support
DataScientest du Bloc 2.

## Parcours conseillé

```text
01. Labs 01 → 06
02. Lab 07 End-to-End
03. Examen blanc 01 — 4 h chrono
04. Post-mortem
05. Corrigé
06. Refaire uniquement les briques faibles
```

## Structure

```text
exam/
  sujet/
  starter_project/
  correction/

labs/
  LAB_01_JSON_JUPYTER_PANDAS/
  LAB_02_ETL_PYTHON/
  LAB_03_DOCKER_COMPOSE_DB/
  LAB_04_SQLALCHEMY_ORM/
  LAB_05_INGESTION_AND_TESTS/
  LAB_06_MACHINE_LEARNING_JOBLIB/
  LAB_07_END_TO_END_CHALLENGE/

resources/
  documents de préparation 00 → 10
```

## Règle principale

Pour l'examen blanc, n'ouvrez pas `exam/correction/` avant d'avoir :
1. arrêté le chrono ;
2. créé votre archive de rendu ;
3. noté votre post-mortem.
