# Sources et périmètre

Le pack est construit à partir des thèmes explicitement annoncés pour le Bloc 2 :

```text
JSON / Jupyter
Python structuré
pandas / matplotlib
valeurs manquantes
colonnes catégorielles
base relationnelle / Docker
variables d'environnement
schéma logique / PK / FK
SQLAlchemy / ORM
scikit-learn
évaluation / joblib
docker-compose
tests d'ingestion
impact écologique
```

Les labs, datasets synthétiques, scénarios métier, choix d’algorithmes et architectures de
démonstration sont des **supports d’entraînement proposés**, et non des contenus officiels
de l’examen réel.
